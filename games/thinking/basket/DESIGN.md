# 쏙쏙 바구니 기획서

아이가 바구니 이름과 예시 두 개를 보고, 같은 무리에 속하는 새 물건을 골라 담는다. 서로 다르게 생긴 물건도 ‘과일’이나 ‘탈것’처럼 한 이름으로 묶을 수 있다는 점을 놀이로 경험한다.

## 한 문제를 노는 방법

‘과일 바구니’에 사과와 배가 보인다. 보기가 바나나·기차·티셔츠라면 아이는 바나나를 누른다. 맞히면 바나나가 두 예시 옆에 놓여 세 과일을 한눈에 볼 수 있다. 물건은 보기 버튼을 한 번 눌러 담는다.

## 바구니 구성과 피드백

| 무리 | 들어갈 수 있는 것 |
| --- | --- |
| 과일 | 사과, 배, 바나나, 포도 |
| 탈것 | 자동차, 기차, 버스, 자전거 |
| 옷 | 티셔츠, 바지, 외투, 원피스 |
| 악기 | 북, 피아노, 기타, 나팔 |
| 동물 | 토끼, 강아지, 호랑이, 코끼리 |

한 판에 다섯 바구니가 한 번씩 섞여 나온다. 각 무리의 네 항목에서 예시 두 개와 정답 한 개를 서로 다르게 뽑는다. 오답 두 개도 서로 다른 무리에서 하나씩 뽑는다. 오답을 고르면 바구니는 그대로이고, 같은 문제의 두 번째 오답부터 정답 테두리가 반짝인다. 바구니를 하나 완성할 때마다 별을 하나 모은다.

## 검토할 장면

- 예시에 나온 두 물건이 정답 보기에 다시 나오지 않는지, 보기 중 같은 무리의 물건은 하나인지 본다.
- 잘못 누른 물건은 바구니에 들어가지 않아야 한다. 정답을 여러 번 눌러도 세 번째 물건과 보상 별은 한 번씩만 추가되어야 한다.
- 다섯 종류의 바구니를 모두 채운 후 결과에서 별 다섯 개를 확인한다.
