# 꼬마 동물 탐정 기획서

아이가 두 단서를 듣고 떠올린 동물을 그림에서 찾는 놀이다. 글을 읽기 전에도 풀 수 있도록 단서 그림 두 개, 단서 문장, 안내 음성을 함께 제공한다.

## 한 문제를 노는 방법

귀와 당근 그림 옆에 ‘귀가 길고 당근을 좋아해.’가 뜬다. 소리가 켜져 있으면 질문에 이어 단서가 들린다. 아이는 동물 그림과 이름이 붙은 보기 세 개 중 토끼를 누른다. ‘다시 듣기’를 누르면 질문과 해당 동물의 단서를 다시 들을 수 있다.

## 단서와 출제

| 찾을 동물 | 단서에 담긴 특징 |
| --- | --- |
| 토끼 | 긴 귀, 당근 |
| 고양이 | 야옹 하는 소리, 수염 |
| 오리 | 꽥꽥 우는 소리, 물에서 헤엄치기 |
| 코끼리 | 긴 코, 큰 귀 |
| 소 | 음매 하는 소리, 우유 |
| 꿀벌 | 붕붕 날기, 꽃에서 꿀 모으기 |

여섯 동물 중 다섯을 섞어 한 번씩 출제한다. 보기에는 목표 동물과 다른 동물 두 마리가 나온다. 틀리면 단서를 다시 살펴볼 수 있고, 두 번 틀리면 정답 보기에 테두리 힌트가 뜬다. 맞힌 동물마다 별 하나를 모아 다섯 문제 뒤 결과를 연다.

## 검토할 장면

- 토끼 문제에서 음성을 다시 듣고 귀·당근 그림과 같은 특징을 알려 주는지 확인한다. 소리를 꺼도 그림과 문장으로 답을 찾을 수 있어야 한다.
- 보기 세 개에 서로 다른 동물이 있고, 이번 단서와 맞는 동물이 하나인지 본다. 오답 뒤에도 같은 단서로 다시 시도할 수 있어야 한다.
